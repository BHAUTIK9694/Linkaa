# OG Image (Open Graph)

Place a file named `og-image.jpg` in this directory (`public/`).

## Requirements
- Dimensions: 1200 × 630 pixels (recommended by Facebook/LinkedIn/Twitter)
- Format: JPEG (best compression for photos)
- File size: under 300 KB
- Content: Brand logo "Livantaa" with tagline "Furniture, crafted to endure." on a dark background showing a furniture piece

This image appears when the website URL is shared on social media platforms.
